# Product demo video

`vivary-demo-beta1.mp4` is a 56-second screen recording of Vivary 0.1.0-beta.1, recorded November 1, 2026. It shows a user create a project, ask Claude Code to write a file, open the file, save a project fact, check project health and search the project. On-screen captions name each step. The agent's turn plays at three times its speed. The video has no sound.

The app was the published portable ZIP `Vivary-0.1.0-beta.1-windows-x64.zip`. Its SHA-256 matched the release's checksum file, and its `BUILD-INFO.json` names source commit 09cfdd12e6dafce8305ea9cb7ef8fcb0d5c14796. It ran on Windows 11 with a separate, disposable app profile and Jeff's Claude Code sign-in, which Jeff approved for the recording. Frames came from the app's own renderer through the Chrome DevTools Protocol. The drawn cursor and the captions were added for the recording. No private project content, account identifier or user path appears in any frame.

`vivary-demo-beta1-poster.webp` is one recorded frame, without the caption: the agent's new file open in Files.
