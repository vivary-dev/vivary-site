# Hero

The vivarium in cross section, for the home page hero. A glass cloche over four strata, ferns and sprouts, stones, a door at the edge of the world, a label leaning on the plate with three lines, the last in amber.

- `vivary-hero-vivarium.svg`: the source. Line art and dither in text #EBE5D8, text-2 #A69D8D and text-3 #837C6F on ground #080705. Amber #E9A23B once, on the recorded line.
- `vivary-hero-vivarium.png`, `.webp`: 1600 by 900 renders for `public/`.

No gradients, no glow, no photograph. Sized for the 7fr column beside the headline.
