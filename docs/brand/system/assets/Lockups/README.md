# Lockups

Mark plus wordmark, paths only, clear space equal to the mark's height inside the viewBox. Ink baked in: bone for the site ground, lime for the app ground, black for white.

- `vivary-lockup-horizontal-{bone,lime,black}.svg`: mark 1.12 times cap height, gap 0.45 times cap height.
- `vivary-lockup-stacked-{bone,lime,black}.svg`: mark 1.5 times cap height, centered.
- `vivary-lockup-horizontal-tagline-B-bone.svg`, `vivary-lockup-stacked-tagline-B-bone.svg`: with the recommended tagline, "It knows you. Because you wrote it down." The claim in Big Shoulders 800, opsz 72, same ink as the wordmark.
- `vivary-lockup-horizontal-tagline-A-bone.svg`, `vivary-lockup-stacked-tagline-A-bone.svg`: with "Your projects. Your agents. Your machine." for comparison.
