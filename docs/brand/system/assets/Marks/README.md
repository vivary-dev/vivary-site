# Marks

Single ink SVGs. The ink is baked in, so pick the file for the ground. Each mark is one flattened path on a 64 unit canvas.

- `vivary-mark-jar-bone.svg`: the mark, bone #EBE5D8, for the site ground.
- `vivary-mark-jar-lime.svg`, `-apptext.svg`: lime #B8F263 or the app's off-white #EDF4EF, for the app ground.
- `vivary-mark-jar-black.svg`: warm black #080705, for white and print.
- `vivary-mark-jar-sizes.png`: the mark at 256, 32 and 16 px on the three grounds. No small cut.
- The family, bone and lime, for section objects and illustration, never as a second logo: `vivary-mark-dome-sprout-*`, `vivary-mark-cloche-wavy-*`, `vivary-mark-strata-sprout-*`, `vivary-mark-wave-globe-*`, `vivary-mark-seed-world-*`, and the first round's `vivary-mark-vivarium-*`.
- `vivary-mark-round-2.png`: the six of round two side by side at 256, 32 and 16 px.
