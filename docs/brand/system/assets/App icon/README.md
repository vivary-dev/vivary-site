# App icon

Per the asset brief: the mark on a rounded tile with its own background, because Windows shows icons on light and dark taskbars.

- `vivary-appicon-1024.svg`, `vivary-appicon-1024.png`: the master. Tile #0C100E, corner radius 22%, the jar in lime #B8F263 at 78% of the tile.
- `vivary-appicon-small-sizes.png`: how it reads at 16, 24, 32 and 48 px on a dark and a light Windows taskbar.
- `vivary-appicon-alt-lime-1024.svg`, `-256.png`: the lime tile alternative, kept for comparison.

Vivary.ico (256, 128, 64, 48, 32, 24, 16, all from the master) is built from the master. Destination: Vivary-New `packages/desktop/`. An `.icns` is not built yet.
