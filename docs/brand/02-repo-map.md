Active sibling repositories including `patchbraid`, `callout` and
`agent-workspace-catalog` keep their own identities. GitHub lists `harnessmax`,
`harnessmax-planning` and `web-system` as archived. No sibling or archived
repository changes are part of this rollout.

The single current Vivary asset authority is
[the brand system](system/README.md#mascot-and-agent-character). The manifest
records intended consumers, not proof of deployment. Product availability in
older site research is dated. Check the current product source before changing
claims. Production domain selection and publication remain separate decisions.
