# Vivary home page, knowledge first

Two static pages built from the design canvas on 2026-09-16.

- index.html: the desktop layout (1440 grid, fluid up to that width).
- phone.html: the phone layout (390 grid, fluid up to 480).
- assets/: the jar mark, the horizontal lockup, the hero vivarium PNG and four family marks, all in bone on the site ground.

Fonts load from Google Fonts (Big Shoulders, Fraunces, Geist Mono, Inter). Swap the link in the head for the font files in the design system if you want them self-hosted.

Not done yet: one responsive page. The two files are separate layouts, not one page with breakpoints. All styles are inline, so merging them means moving the layout rules into a stylesheet first.
